# Monkey Barber Shop — versão para Spck

Esta versão usa apenas HTML + CSS + JavaScript. Não usa React, Vite ou Node.

Arquivos:
- index.html
- style.css
- script.js

No Spck: abra `index.html` e toque no botão ▶️.

Antes de publicar, troque o número demonstrativo no `script.js` e personalize textos, preços e fotos.
